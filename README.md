# Sales Tracking System

An academic PHP/MySQL e-commerce and sales tracking system developed as part of an undergraduate Computer Science project.

## Included functionality

- User authentication and role-based access
- Product management for administrators and vendors
- Sales reporting and dashboard statistics
- Product ratings
- Customer-facing market and purchasing pages
- Payment callback handling

## Technology

- PHP
- MySQL / MySQLi
- HTML, CSS and JavaScript (where included in the source)

## Setup notes

1. Install a local PHP/MySQL environment such as XAMPP.
2. Create the database expected by `connectDb.php`.
3. Review and update local database credentials in `connectDb.php`.
4. Place the project in the web server directory and open `index.php`.

This repository contains the available source code. Database exports, credentials and production configuration should be added separately only after review.
